Exercice 5 - MySQL et Adminer

docker network create reseau-mysql
docker volume create mysql-data
docker run -d --name mysql --network reseau-mysql --restart unless-stopped -v mysql-data:/var/lib/mysql -e MYSQL_ROOT_PASSWORD=rootpass -e MYSQL_DATABASE=ma_base -e MYSQL_USER=ulysse -e MYSQL_PASSWORD=motdepasse mysql:8
docker run -d --name adminer --network reseau-mysql --restart unless-stopped -p 8080:8080 adminer

Connexion Adminer (http://localhost:8080): systeme MySQL, serveur "mysql", utilisateur ulysse, base ma_base.

Table de test:
CREATE TABLE etudiants (id INT AUTO_INCREMENT PRIMARY KEY, nom VARCHAR(50));
INSERT INTO etudiants (nom) VALUES ('Alice'),('Bob'),('Chloe');

Verifications:
- Persistance: docker rm -f mysql puis meme docker run -> les 3 lignes sont toujours presentes.
- Isolation: port 8080 ouvert (Adminer), port 3306 non joignable depuis l'hote.
- Resolution par nom: adminer resout "mysql" en 172.25.0.2.
- Redemarrage auto: un conteneur qui plante seul est relance (RestartCount=3).
  Note: "docker kill" est considere comme un arret manuel et n'est pas relance par unless-stopped.

Bonus: docker compose up -d (voir compose.yaml)
